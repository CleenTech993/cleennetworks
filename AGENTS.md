- Console layouts (/tenant, /super-admin) use ssr:false + requireConsole() (signed in, OTP aal2, role) — session lives in browser storage, so server render can't see it.
- Database migrations: two tracks, applied in this order by `tests/sql/build-db.sh` (the single source of truth for ordering) — `supabase/migrations/*.sql` by version, with `drizzle/migrations/000*.sql` slotted in before `20261024000000` (they create `router_metrics`/`router_interfaces`). Name files `<14-digit version>_name.sql` (anything else is rejected). Write new migrations so they can be re-run safely (`IF NOT EXISTS`, `DROP POLICY/TRIGGER IF EXISTS` before `CREATE`, `CREATE OR REPLACE`): a migration pasted into the SQL editor and later re-applied by the pipeline must not stop halfway and block the ones after it. After adding or changing a migration run `npm run db:verify-gen` (regenerates `supabase/verify_live_db.sql`) and `npm run test:sql` (fails if that file is stale). `supabase/README.md` explains how to check the live database.
- SEO: `src/lib/seo.ts` is the single source of truth for public pages (`PUBLIC_PAGES`: title <= 60 chars, description 70-160, both unique), the head/JSON-LD builders, and the `robots.txt` / `sitemap.xml` generators (served by `src/routes/robots[.]txt.ts` and `sitemap[.]xml.ts`). Addresses are never hard-coded: `siteOrigin()` (`src/lib/site-origin.ts`) uses the host the request arrived on, or `VITE_SITE_URL` if set — set it once a custom domain exists so previews and mirrors canonicalise to it. A new public page: add it to `PUBLIC_PAGES`, give its route `head: () => pageHead("/path", siteOrigin(), [...])`, and put real text in the page (it is server-rendered). Every other top-level route must carry `noindex` (sign-in, consoles, `/p/<slug>` portals): `tests/seo-routes.test.ts` fails otherwise, because a page with no robots tag is indexable by default. `createFileRoute` needs a string literal, not a constant. Marketing claims (rates, intervals, payment methods) must match the code — re-check them when those change.
